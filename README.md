# CS-320-Software-Test-Automation-QA
CS 320 Software Test Automation and Quality Assurance portfolio artifacts


### How can I ensure that my code, program, or software is functional and secure?

I can make sure my software is functional by testing it throughout the development process instead of waiting until the end. During this course, I used JUnit tests to check different requirements and make sure the program handled both valid and invalid information correctly. Testing individual parts of the program helped me find problems before they could affect other parts of the software. I also learned that reviewing requirements carefully and testing different situations can help make software more reliable and secure.

### How do I interpret user needs and incorporate them into a program?

I start by looking at the requirements and identifying exactly what the user expects the program to do. I then turn those requirements into features and rules that can be implemented and tested. For example, the contact service had specific requirements for information such as contact IDs, names, phone numbers, and addresses. I had to make sure my code followed those requirements while also creating tests to verify that incorrect information would not be accepted. This showed me how important it is to keep the user's needs in mind throughout development and testing.

### How do I approach designing software?

I approach software design by breaking a larger problem into smaller parts that are easier to develop and test. Before writing code, I try to understand what the program needs to accomplish and how the different classes and methods should work together. I also think about how each requirement can be tested while I am developing the program. This course helped me understand that testing should be part of the design process instead of something that is only done after the software is finished.
